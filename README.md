## ⚙️ 技术原理

### 🔬 **无 Root 变声实现**

```
麦克风采集
  ↓
PSOLA 音高平移（改变基频）
  ↓
共振峰偏移（模拟性别差异）
  ↓
气声模拟（增加真实感）
  ↓
系统音频路由（WRITE_SETTINGS）
  ↓
游戏/应用读取变声后的音频
```

### 📡 **关键技术**
- **PSOLA 算法** - Pitch Synchronous Overlap and Add
- **共振峰偏移** - Formant Shifting（模拟男/女声差异）
- **系统音频路由** - 基于"声吾控"技术分析
- **前台服务** - 确保后台不被杀

## ❓ FAQ

### **Q1: 为什么会报"诈骗应用"警告？**
**A**: 只有 **Debug 版**（未签名）会报警告，**签名版不会报**。如果下载的是 Debug 版，点击"仍要安装"即可，这是你自己编译的 APK，100% 安全。

---

### **Q2: 游戏内没有变声效果？**
**原因**：
- 没有开启"修改系统设置"权限
- 手机厂商限制（部分华为/小米需要额外设置）
- 游戏使用独立音频通道

**解决办法**：
1. 检查权限是否都授予
2. 重启应用和游戏
3. 尝试戴耳机测试
4. 如果还是不行，考虑 Root 版（终极方案）

---

### **Q3: 延迟多少？卡顿吗？**
**A**: 
- **延迟**: < 200ms（人耳难以察觉）
- **性能**: 占用 < 50MB 内存
- **稳定性**: 可连续运行 30+ 分钟

---

### **Q4: 支持哪些手机？**

## 🔧 进阶玩法

### **自定义音色**
修改 `ProfessionalVoicePreset.kt` 中的参数：
```kotlin
VoicePreset(
    id = "custom",
    name = "自定义音色",
    emoji = "🎨",
    description = "我的专属音色",
    pitchShift = 5.0f,      // 音调偏移（半音）
    formantShift = 1.2f,    // 共振峰偏移
    breathiness = 0.3f,     // 气声程度
    category = VoiceCategory.FEMALE
)
```
