========================================
🚀 三种部署方式（任选其一）
========================================

方式1️⃣：运行自动脚本（最简单）
------------------
cd /root/VoiceChanger
./auto_deploy.sh

然后按提示选择：
- 选项1：如果已创建GitHub仓库
- 选项2：查看演示和手动命令
- 选项3：使用GitHub Token自动创建


方式2️⃣：手动命令（4步完成）
------------------
1. 创建 GitHub 仓库
   访问：https://github.com/new
   名称：VoiceChanger
   点击：Create repository

2. 推送代码
   cd /root/VoiceChanger
   git remote add origin https://github.com/你的用户名/VoiceChanger.git
   git branch -M main
   git push -u origin main

3. 等待编译（3-5分钟）
   访问：https://github.com/你的用户名/VoiceChanger/actions

4. 下载APK
   访问：https://github.com/你的用户名/VoiceChanger/releases


方式3️⃣：使用 GitHub Token（全自动）
------------------
1. 获取 Token
   访问：https://github.com/settings/tokens
   Generate new token (classic)
   勾选：repo 权限
   复制 Token

2. 运行脚本
   ./auto_deploy.sh
   选择选项 3
   输入 Token 和用户名

========================================
📱 编译后的使用
========================================

APK 自动编译完成后：

1. 下载 APK
   - 在 Releases 页面下载
   - 或在 Actions → Artifacts 下载

2. 安装到手机
   adb install app-debug.apk
   或传到手机直接点击安装

3. 使用步骤
   - 打开 APP → 授予录音权限
   - 选择"甜美女声"
   - 点击"开始变声"
   - 打开王者荣耀 → 开启语音
